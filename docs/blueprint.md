# **App Name**: SkillOrbit

## Core Features:

- AI Quiz Generator: Generates multiple choice questions based on subject and topic. Returns JSON.
- AI Tutor: Provides helpful tutoring, analyzes images, explains solutions, and summarizes content with HTML formatting.
- Dyslexia Support (Speech Analysis): Analyzes speech for grammar, corrects gently, and provides encouraging tips for students with dyslexia using HTML.
- Dyslexia Support (Reading Challenge): Compares user speech with target text, provides feedback on pronunciation, and encourages students with dyslexia using HTML.
- User Interface: Provides a friendly UI so students feel at ease while learning.

## Style Guidelines:

- Primary color: Calm Blue (#4CAF50) for a sense of trust and stability.
- Secondary colors: Light Green (#8BC34A) and Pale Yellow (#FFEB3B) for highlighting important elements and creating an inviting atmosphere.
- Accent color: Soft Orange (#FF9800) for CTAs and interactive components.
- Body font: 'Open Sans', a highly readable sans-serif font for body text and general content.
- Headline font: 'Montserrat', a bold and modern sans-serif font for titles and headings.
- Use clear and simple icons to represent different subjects and topics.
- Clean and spacious layout with clear content hierarchy to reduce visual clutter.
- Subtle transitions and animations to provide feedback and enhance user experience.
